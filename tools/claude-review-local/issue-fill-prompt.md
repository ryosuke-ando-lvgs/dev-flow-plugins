## やってほしいこと

現在の本文は、Issueテンプレート（bug/story等）の項目見出しだけがあり、各項目の中身が
空・プレースホルダのまま、またはタイトルから推測できる範囲でしか書かれていない状態です。
タイトルと、必要であれば `Read`/`Grep`/`Glob` で調査した内容をもとに、
**本文の項目構成（見出し・フィールド名・チェックボックス等）は一切変更せず**、各項目の
中身だけを具体的な内容で埋めてください。

- 見出しの追加・削除・並び替え・文言変更はしない。既存のMarkdown構造（`##`見出しや
  フォームのフィールド名、チェックボックス項目など）をそのまま維持し、その下や右側の
  内容だけを書き換える。
- 憶測で断定しすぎない。コードから確認できた事実と、タイトルからの推測を区別し、
  推測部分は「〜と推測されます」「要確認」のように明記する。
- 調査しても具体的な内容を埋められない項目は、無理に埋めずに
  「（要追記: 〜の情報が必要）」のように、何が足りないかを明記したプレースホルダを残す。
  内容を捏造しない。
- bug系Issueなら再現手順・期待動作・実際の動作・影響範囲など、story系Issueなら
  背景・目的・受け入れ条件など、テンプレートの各項目の意図に沿って埋める。

## 出力形式（厳守）

他の前置き・後書きは一切書かず、必ず以下の形式のみを出力してください。

```
---
<埋め込み後のIssue本文全体（既存の項目構成を維持したMarkdown）>
```

`---` の後に続く内容が、そのままIssueの新しい本文として置き換えられます。
